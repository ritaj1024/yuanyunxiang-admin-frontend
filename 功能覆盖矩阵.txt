缘·云香后台管理系统 原型功能覆盖矩阵

说明
- 本矩阵用于核对 `缘·云香+后台管理系统需求文档.pdf` 的功能点是否已在原型 DEMO 中落位。
- 对应 DEMO 文件：`index.html`、`styles.css`、`app.js`
- 原型采用 RuoYi / Element Plus 中后台骨架，统一为“菜单入口 + 页面原型 + 功能覆盖 + 关键规则”。

一、香室管理
1. 香型管理
- 覆盖：香型列表、筛选、排序、导出
- 覆盖：显示名称、原命名、文案意境、场景画面、解锁等级、展示排序、状态、累计使用次数
- 覆盖：新增、编辑、上线、下线
- 覆盖：上线前配置完整性校验，下线二次确认

2. 香型新增/编辑
- 覆盖：基本信息表单
- 覆盖：场景背景图、晨/昼/昏/夜、雨天、雪天场景图
- 覆盖：保存、取消、未保存确认
- 覆盖：新增默认下线

3. 香炉材质管理
- 覆盖：材质名称、材质图片、解锁等级、状态
- 覆盖：新增、编辑、启用、禁用
- 覆盖：PNG 透明底素材要求

4. 背景音乐管理
- 覆盖：音频名称、音频文件、默认播放、排序、状态
- 覆盖：新增、编辑、试听、启用、禁用
- 覆盖：MP3 文件限制

5. 上香规则配置
- 覆盖：每日免费次数、总上限、祈福语字数上限、动画时长、成功页时长、冷却间隔
- 覆盖：保存、重置为默认值
- 覆盖：范围校验与即时生效

6. 祈福语管理
- 覆盖：系统推荐祈福语 Tab
- 覆盖：用户祈福语审核 Tab
- 覆盖：新增、编辑、删除、通过、驳回
- 覆盖：敏感词检测、风险等级、替换默认文案、通知用户

7. 上香记录查询
- 覆盖：用户昵称、用户ID、香型、上香日期、祈福语关键词、上香来源筛选
- 覆盖：记录ID、用户头像昵称、香型、祈福语、上香时间、当时排名、上香来源
- 覆盖：导出 xlsx、超大数据异步导出、导出日志
- 覆盖：只读不可修改

二、排行榜管理
1. 排行榜数据
- 覆盖：全国排行榜 Tab
- 覆盖：好友排行榜查询 Tab
- 覆盖：修正数据、封榜、解封
- 覆盖：异常刷榜标记、重新计算排名、客诉排查

2. 排行规则配置
- 覆盖：排名更新时间、月度重置日、排序规则、好友榜展示数量、全国榜展示数量、刷榜阈值
- 覆盖：保存、手动重置排行榜
- 覆盖：下一周期生效与月榜归档

三、分享管理
1. 分享规则配置
- 覆盖：好友分享奖励、朋友圈奖励、好友点击奖励、点击每日上限、新用户注册奖励、总开关
- 覆盖：保存与即时生效
- 覆盖：紧急止损关闭分享奖励

2. 分享卡片配置
- 覆盖：卡片标题模板、卡片封面图、展示字段
- 覆盖：变量 `{香型名}`、`{用户昵称}`
- 覆盖：实时预览
- 覆盖：未上传封面图时回退香型场景图

四、论坛管理
1. 帖子管理
- 覆盖：帖子来源、论坛分类、香型标签、状态、关键词、作者昵称、发布日期筛选
- 覆盖：帖子列表字段、图片预览、互动数据、状态、标记
- 覆盖：通过、驳回、删除、置顶、加精
- 覆盖：批量通过、批量驳回、批量删除、导出
- 覆盖：驳回原因与违规处罚阶梯

2. 审核工作台
- 覆盖：待审核数量、今日已审、平均处理时长
- 覆盖：左右分栏结构
- 覆盖：敏感词高亮、风险等级、相似内容检测、用户历史违规
- 覆盖：快捷键 Y / N / D / →
- 覆盖：自动加载下一条

3. 评论管理
- 覆盖：评论关键词、评论者昵称、所属帖子ID、评论日期筛选
- 覆盖：删除评论、禁言用户
- 覆盖：评论者与帖子跳转
- 覆盖：评论删除后用户端提示文案

4. 举报处理
- 覆盖：帖子/评论举报列表
- 覆盖：举报原因、处理状态、举报日期筛选
- 覆盖：处理弹窗：内容预览、判定结果、处理措施、处理说明
- 覆盖：有效举报 / 无效举报、删除内容、警告、禁言、封禁

5. 论坛分类管理
- 覆盖：分类名称、分类说明、排序、状态
- 覆盖：新增、编辑、启用、禁用
- 覆盖：香型筛选标签与香型管理联动

6. 官方帖子管理
- 覆盖：帖子标题、帖子内容、论坛分类、香型标签、是否置顶
- 覆盖：富文本编辑、图片/链接/文字样式
- 覆盖：发布、编辑、删除
- 覆盖：官方标识、默认置顶、免审核

五、用户管理
1. 用户列表
- 覆盖：用户昵称、用户ID、手机号、等级、状态、注册日期、最后活跃、是否绑定手机筛选
- 覆盖：用户列表字段、排序、状态展示
- 覆盖：详情、禁言、封号、发消息、导出
- 覆盖：角色分权：运营、审核、客服、超级管理员

2. 用户详情
- 覆盖：基础信息、会员信息
- 覆盖：上香记录、发帖记录、评论记录、分享记录、违规记录 Tab
- 覆盖：重置头像、重置昵称、清空签名、解绑手机、调整等级、禁言、封号、发消息、返回
- 覆盖：升级历史与已解锁香型

3. 等级管理
- 覆盖：Lv.1~Lv.6 固定等级配置
- 覆盖：等级名称、升级阈值、解锁香型、解锁材质、解锁特权、徽章图片
- 覆盖：等级分布饼图、升级漏斗图
- 覆盖：阈值递增校验

4. 黑名单管理
- 覆盖：封禁类型、封禁原因、操作人、执行时间、到期时间
- 覆盖：解封、批量解封
- 覆盖：禁言到期自动恢复并通知

5. 积分管理（V2.0 预留）
- 覆盖：积分规则配置
- 覆盖：积分明细查询
- 覆盖：兑换记录

六、消息中心
1. 系统公告管理
- 覆盖：公告列表
- 覆盖：公告标题、公告类型、公告内容、目标用户、生效时间、失效时间
- 覆盖：保存草稿、发布、下线、删除、预览
- 覆盖：弹窗、横幅、消息三种类型
- 覆盖：全部用户、指定等级、指定地区

2. 消息推送
- 覆盖：推送记录 Tab
- 覆盖：消息模板 Tab
- 覆盖：新建推送、发送、模板编辑/删除
- 覆盖：群发、定向、模板变量、单用户每日 5 条频控

3. 意见反馈管理
- 覆盖：反馈列表字段、截图预览、反馈分类、处理状态
- 覆盖：回复、关闭
- 覆盖：回复后通过消息推送回发用户

4. Banner管理（V2.0 预留）
- 覆盖：首页轮播图配置
- 覆盖：跳转链接/小程序页面配置
- 覆盖：展示时段控制

七、数据统计
1. 仪表盘
- 覆盖：DAU、今日上香、今日新增、今日分享、待审核帖子、今日发帖量卡片
- 覆盖：上香趋势图、活跃热力图、香型偏好、新增与留存、TOP10 变动
- 覆盖：流失预警、刷榜预警、内容积压、敏感词高频、性能预警

2. 用户分析
- 覆盖：用户增长、用户留存、用户画像、等级分布、活跃分析
- 覆盖：日期范围导出

3. 上香分析
- 覆盖：总量、趋势、香型偏好、时段分布、祈福语词云、来源分布
- 覆盖：日期范围导出

4. 论坛分析
- 覆盖：发帖/评论趋势、互动率、分类分布、热帖排行、审核统计
- 覆盖：日期范围导出

5. 分享分析
- 覆盖：分享趋势、渠道对比、裂变系数、转化漏斗、邀请排行
- 覆盖：日期范围导出

6. 数据导出
- 覆盖：用户数据、上香记录、帖子数据、评论数据、分享数据、排行榜数据导出
- 覆盖：日期范围、字段勾选、xlsx/csv
- 覆盖：同步下载 / 异步导出、导出记录、下载链接、状态
- 覆盖：操作日志追溯

八、系统管理
1. 账号管理
- 覆盖：账号列表
- 覆盖：新增、编辑、停用、启用、重置密码
- 覆盖：角色分配、邮箱唯一、密码复杂度
- 覆盖：5 次输错锁定 30 分钟

2. 角色权限管理
- 覆盖：角色列表
- 覆盖：新增角色、编辑、权限配置
- 覆盖：树形勾选权限
- 覆盖：香室、排行榜、分享、论坛、用户、消息中心、数据统计、系统管理权限粒度
- 覆盖：预置角色不可删除，可调整权限，可新增自定义角色

3. 操作日志
- 覆盖：登录日志 Tab
- 覆盖：操作日志 Tab
- 覆盖：非常用 IP 登录提醒
- 覆盖：封禁、删除、配置变更、数据导出、公告发布等敏感动作记录
- 覆盖：日志至少保留 180 天

4. 系统配置
- 覆盖：小程序 AppID / AppSecret
- 覆盖：敏感词库增删改查与批量导入
- 覆盖：论坛发帖、分享奖励、排行榜展示、用户注册四个功能开关
- 覆盖：保存时管理员密码二次验证
- 覆盖：配置变更日志

九、扩展规划位
1. 积分管理（V2.0 预留）
- 覆盖：积分规则配置、明细查询、兑换记录

2. 活动管理（P3 预留）
- 覆盖：活动列表、活动规则、活动素材、效果数据

3. 每日运势（P3 预留）
- 覆盖：运势文案配置、发布日期计划、展示状态、效果监控

十、统一交互与安全要求
- 覆盖：删除、封禁、修正数据、导出、系统配置保存等敏感动作的确认机制
- 覆盖：列表页查询区、工具栏、主体区、分页区统一模板
- 覆盖：表单页必填校验、取消确认、统一按钮顺序
- 覆盖：HTTPS、JWT、RBAC、二次验证、XSS/CSRF、防注入、频率限制、数据脱敏、密码策略等安全要求的原型承载位
